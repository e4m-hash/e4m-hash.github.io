# 보안과 개인정보

학습 데이터와 model endpoint는 최소 권한, 추적 가능한 접근과 민감정보 경계를 가져야 합니다.

## 핵심

- 수집 목적과 보존 기간이 없는 민감정보는 저장하지 않습니다.
- artifact storage, registry와 API 권한을 분리합니다.
- secret을 code, image와 model artifact에 포함하지 않습니다.

## 연습

- [ ] 데이터 수집부터 inference log까지 민감정보가 지나가는 경로를 표시합니다.
