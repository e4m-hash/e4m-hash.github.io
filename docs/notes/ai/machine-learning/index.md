# 머신러닝 (Machine Learning)

ML Engineer에게 필요한 모델링과 시스템 구현 내용을 학습 순서대로 정리합니다.

![[ml-engineer-study.base#전체 학습 노트]]

## 학습 순서

1. [[foundations/index|머신러닝 기초]] — 문제 정의, split, 일반화와 최적화
2. [[data/index|ML 데이터]] — 품질 검사, 전처리, feature와 SQL
3. [[models/index|머신러닝 모델]] — 주요 모델군과 선택 조건
4. [[evaluation/index|모델 평가]] — baseline, metric, calibration과 오류 분석
5. [[engineering/index|ML Engineering]] — pipeline, test, serving과 운영
6. [[docs/notes/ai/deep-learning/index|딥러닝]] — 신경망, Transformer와 LLM
7. [[career/index|커리어 준비]] — 포트폴리오와 면접

## 완료 기준

- 개념을 자신의 데이터와 실패 사례로 설명한다.
- notebook 밖에서 학습·평가·예측을 재현한다.
- metric, latency, 비용과 제한 조건을 측정해 남긴다.
- `planned` 노트는 코드·실험·문서 근거가 생기면 `in-progress`로 바꾼다.
