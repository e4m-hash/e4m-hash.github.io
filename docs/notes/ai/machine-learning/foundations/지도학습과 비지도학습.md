# 지도학습과 비지도학습

label의 유무보다 결과를 어떤 방식으로 검증할 수 있는지가 문제 유형을 나눕니다.

## 핵심

- 분류는 class, 회귀는 연속값을 예측합니다.
- 비지도학습은 군집·표현·이상 탐지 결과의 유용성을 별도로 검증합니다.
- self-supervised 표현도 downstream task에서 평가합니다.
