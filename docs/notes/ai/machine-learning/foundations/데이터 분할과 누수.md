# 데이터 분할과 누수

split은 행을 무작위로 나누는 절차가 아니라 실제 일반화 경계를 재현하는 설계입니다.

## 핵심

- subject, cohort, time처럼 독립 단위를 기준으로 나눕니다.
- 전처리와 feature selection은 train fold 안에서만 학습합니다.
- test 결과는 최종 평가 전까지 모델 선택에 사용하지 않습니다.
