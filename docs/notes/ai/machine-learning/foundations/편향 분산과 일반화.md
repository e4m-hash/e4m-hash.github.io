# 편향 분산과 일반화

train과 validation의 차이를 보고 모델 용량, 데이터 양, regularization을 조정합니다.

## 핵심

- 둘 다 나쁘면 underfitting, train만 좋으면 overfitting을 의심합니다.
- 복잡한 모델보다 학습 곡선과 반복 검증으로 원인을 확인합니다.
- 분포가 다른 cohort 성능을 평균과 함께 봅니다.
