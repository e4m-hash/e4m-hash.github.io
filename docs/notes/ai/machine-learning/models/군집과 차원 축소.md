# 군집과 차원 축소

군집과 차원 축소 결과는 정답 metric 하나보다 안정성과 downstream 유용성으로 봅니다.

## 핵심

- 거리와 scaling 선택이 cluster 형태를 바꿉니다.
- PCA는 분산을 보존하지만 label 분리를 보장하지 않습니다.
- 시각화용 embedding과 모델 입력용 표현을 구분합니다.

## 연습

- [ ] seed와 표본을 바꿔 cluster assignment 안정성을 비교합니다.
