# 이력서와 프로젝트 설명

프로젝트 설명은 문제, 역할, 선택, 측정 결과와 제한 조건이 한 흐름으로 읽혀야 합니다.

## 핵심

- 사용한 기술보다 해결한 병목과 검증 방법을 먼저 씁니다.
- 수치는 측정 조건과 비교 기준을 함께 적습니다.
- 팀 작업은 본인의 결정과 기여 범위를 구분합니다.

## 연습

- [ ] 프로젝트 하나를 30초, 3분, 한 페이지 버전으로 각각 정리합니다.
